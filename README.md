# Ehliyet 2027 — SaOz

Uygulamanın herkese açık tanıtım, gizlilik, hesap silme ve kullanım koşulları sayfaları.

Site: https://saidozaydin.github.io/ehliyet2027-site/

Destek: ehliyet2027destek@gmail.com

## Güncelleme

`python build.py` komutu sayfaları `docs/` içine üretir. Tasarım ve font dosyaları `docs/assets/` içindedir. GitHub Pages kaynağı `main` dalındaki `/docs` dizinidir. Dosyaları güncelleyip `main` dalına göndermek siteyi yeniden yayınlar.

Uygulama kaynak kodu, API anahtarı veya kullanıcı ilerlemesi bu depoda bulunmaz.
